# Hundsvängen

PWA-prototyp (Next.js + Tailwind) för att se vilka hundar som är ute i parken innan promenaden.

## Kör lokalt

```bash
npm install
npm run dev
```

Öppna http://localhost:3000 — vyn är 390×844 i en iOS-ram.

## Flöde

Onboarding → Hem → Starta Lugn → Karta med Bella/Kalle/Maja → Hundkort → Avsluta.
